# Python Basics – Tasks Overview

## Task 1: Python Environment Setup & First Script

### Description
This task demonstrates Python installation, basic scripting, variables, input/output,
and running a Python file using an IDE and terminal.

### Files Included
- hello_world.py
- Output screenshot

### Concepts Covered
- Python installation
- Variables
- User input
- Printing output
- Running Python scripts from terminal


## Task 2: Python Data Types & Type Casting

### Description
This task focuses on understanding Python’s built-in data types, performing arithmetic
operations, handling user input, type casting, error handling, string concatenation,
and demonstrating Python’s dynamic typing behavior.

### Files Included
- datatypes_demo.py
- Output screenshot

### Concepts Covered
- Integer, Float, String, Boolean data types
- type() function
- Arithmetic operations
- User input handling
- Type casting (int(), float(), str())
- Error handling using try-except
- String and number concatenation
- Dynamic typing in Python
- Code documentation using comments


## Task 3: Conditional Statements – Grade Calculator (Today’s Task)

### Description
This task demonstrates the use of conditional statements in Python by building a
simple grade calculator. The program takes marks as input, validates the input,
determines grades using if-elif-else statements, applies logical operators, and
prints appropriate messages based on the grade.

### Files Included
- grade_calculator.py
- Output screenshot

### Concepts Covered
- Conditional statements (if, elif, else)
- Logical operators (and, or)
- Nested conditions
- Input validation
- Handling invalid inputs
- Writing clean and readable driver code
- Simulating real-world business rules


## How to Run the Scripts

1. Open the project folder in VS Code or any IDE.
2. Open the terminal.
3. Run the script using:

   --> python hello_world.py

   --> python datatypes_demo.py

   --> python grade_calculator.py
